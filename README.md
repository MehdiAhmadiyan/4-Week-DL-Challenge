# 🚀 4-Week Deep Learning & PyTorch Challenge

Welcome to my Deep Learning Challenge repository!

## 🧠 About This Challenge
Having successfully built a solid foundation in classic Machine Learning, this repository marks my transition into the world of Deep Learning and Artificial Neural Networks. 

The core philosophy of this phase is the **"Dirty Hands" approach**. Instead of passive reading, this challenge is built on translating deep theoretical and mathematical intuitions into pure, hands-on **PyTorch** implementations. The ultimate goal is to move from understanding concepts on paper to actively building, debugging, and training complex neural architectures.

## 🎯 Objectives
- **Hands-on Implementation:** Translate complex network architectures into functional, modular PyTorch code.
- **The "Run and Debug" Rule:** Prioritize live coding, executing every cell, and mastering the art of debugging tensor shapes (Dimension Mismatch).
- **Architecture Mastery:** Focus on understanding the input/output flow of layers and data pipelines rather than just memorizing syntax.
- **Cloud Execution:** Utilize cloud environments (e.g., Google Colab) to train models, bridging the gap between local testing and scalable execution.

## 📂 Repository Structure
- `📁 notes/` - Theoretical takeaways, network architecture diagrams, and core intuitions.
- `📁 notebooks/` - Jupyter Notebooks focusing on step-by-step model building, tensor manipulations, and live debugging experiments.
- `📁 scripts/` - Modular Python scripts containing custom PyTorch training loops, data loaders, and model evaluation metrics.

## 🗺️ Core Topics Covered
Throughout this challenge, I will be implementing and organizing concepts that form the foundation of modern AI:
- **PyTorch Fundamentals:** Tensors, the Autograd mechanism, and building standard PyTorch training/testing loops.
- **Artificial Neural Networks (ANNs):** Building Multi-Layer Perceptrons (MLPs) and understanding Backpropagation practically.
- **Training Deep Networks:** Advanced Optimizers (Adam, RMSprop), Activation functions, Batch Normalization, Dropout, and handling vanishing gradients.
- **Deep Computer Vision:** Convolutional Neural Networks (CNNs), pooling layers, and working with image data.
- **Sequence Processing:** RNNs, LSTMs, and GRUs for time-series and text data.
- **Transformers & Attention:** The foundational architectures behind Generative AI and modern Large Language Models.
