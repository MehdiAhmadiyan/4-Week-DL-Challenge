# 📈 Supervised Learning with Neural Networks

## 1. The Economic Value
*   Despite the immense hype surrounding neural networks, almost all of the massive economic value they have created so far has come from one specific type of machine learning: **Supervised Learning**.
*   In supervised learning, the algorithm simply learns a function mapping from some input ($x$) to a specific output ($y$).

## 2. Applications & Architectures
A lot of value creation comes from cleverly selecting what $x$ and $y$ should be, and choosing the right neural network architecture for that specific data:

*   **Real Estate:** Input = Home features, Output = Price. Architecture: **Standard NN**.
*   **Online Advertising:** Input = Ad & User info, Output = Click on ad? (0/1). By showing users the ads they are most likely to click on, this has become the most lucrative application of deep learning today. Architecture: **Standard NN**.
*   **Photo Tagging (Computer Vision):** Input = Image, Output = Object index (1 to 1000). Architecture: **Convolutional Neural Network (CNN)**.
*   **Speech Recognition:** Input = Audio, Output = Text transcript. Because audio is played out over time (a 1D temporal sequence), this requires a **Recurrent Neural Network (RNN)**.
*   **Machine Translation:** Input = English text, Output = Chinese text. Language is also sequence data, requiring more complex **RNNs**.
*   **Autonomous Driving:** Input = Image & Radar info, Output = Position of other cars. Architecture: **Custom/Hybrid NN**.

## 3. Structured vs. Unstructured Data

**Structured Data:**
*   Refers to databases where every column or feature has a very well-defined meaning (e.g., house size, user age, ad ID).
*   While less glamorous, structured data is responsible for a massive amount of the short-term economic value generated by neural networks (e.g., advertising systems, profit recommendations).

**Unstructured Data:**
*   Refers to raw data like audio, images, or text, where the features are individual pixels or words.
*   Humans evolved to be exceptionally good at interpreting unstructured data, but computers historically struggled with it.
*   Deep learning has drastically improved computers' ability to process unstructured data. This is why it receives so much media hype—a neural network successfully recognizing a cat is highly relatable and cool, even if structured data makes more money.
